# SAME70-XPLD GUI Communication Monitor

## 🖥️ 실시간 통신 모니터링 도구

이 GUI 도구는 SAME70-XPLD 보드와의 UART 통신을 실시간으로 모니터링하고 분석하는 강력한 도구입니다.

## ✨ 주요 기능

### 📡 연결 관리
- **자동 COM 포트 감지**: 사용 가능한 모든 COM 포트 자동 검색
- **유연한 보드레이트 설정**: 9600 ~ 921600 bps 지원
- **실시간 연결 상태 표시**: 연결/해제 상태를 시각적으로 확인

### 📊 실시간 통계 모니터링
- **패킷 통계**: 송신/수신/손실 패킷 수 실시간 표시
- **지연 시간 측정**: 평균/최소/최대 End-to-End 지연 시간
- **패킷 손실률**: 실시간 패킷 손실률 계산 및 표시
- **데이터 전송률**: 초당 바이트 전송량 모니터링

### 📈 시각적 차트
- **지연 시간 그래프**: 실시간 latency 변화 추이
- **패킷 손실률 그래프**: 시간별 패킷 손실률 변화
- **동적 업데이트**: 100ms 주기로 차트 자동 갱신

### 🎮 테스트 기능
- **수동 명령 전송**: 사용자 정의 명령 전송
- **자동 테스트**: 설정 간격으로 자동 패킷 전송
- **시퀀스 번호 추적**: 패킷별 고유 번호로 지연시간 정확 측정

### 📝 로깅 기능
- **실시간 로그**: 모든 송수신 데이터를 타임스탬프와 함께 표시
- **컬러 코딩**: TX(파란색), RX(초록색), Error(빨간색) 구분
- **로그 저장**: 통계 정보와 함께 텍스트 파일로 저장

## 🚀 빠른 시작

### 1. 의존성 설치
```bash
# 자동 설치 (권장)
double-click launch_monitor.bat

# 또는 수동 설치
pip install -r requirements.txt
```

### 2. GUI 실행
```bash
# 배치 파일 사용 (Windows)
launch_monitor.bat

# 또는 직접 실행
python same70_gui_monitor.py
```

### 3. 연결 설정
1. **COM Port 선택**: 드롭다운에서 SAME70-XPLD 포트 선택
2. **Baudrate 설정**: 보통 115200 bps 사용
3. **Connect 버튼 클릭**: 연결 시작

### 4. 통신 테스트
1. **Send Command 입력**: 예) "TEST", "STATUS", "DATA" 등
2. **Send 버튼 클릭** 또는 **Enter 키**: 명령 전송
3. **Auto Test 체크**: 자동 반복 테스트 활성화

## 📊 성능 지표

### End-to-End 지연시간 측정
- **방식**: 시퀀스 번호를 포함한 패킷 송신 → 응답 수신 시간 측정
- **정확도**: 마이크로초 단위 타임스탬프 사용
- **통계**: 평균, 최소, 최대값 실시간 계산

### 패킷 손실률 계산
```
패킷 손실률 = (송신 패킷 수 - 수신 패킷 수) / 송신 패킷 수 × 100%
```

### 실시간 업데이트
- **GUI 갱신**: 100ms 주기
- **차트 업데이트**: 실시간 (최근 100개 데이터 포인트)
- **통계 계산**: 패킷 수신 즉시

## 🐛 문제 해결

### 연결 실패
1. **COM 포트 확인**: 장치 관리자에서 SAME70-XPLD 포트 확인
2. **포트 사용 중**: 다른 프로그램에서 포트 사용 중인지 확인
3. **드라이버 설치**: SAME70-XPLD USB CDC 드라이버 설치 확인

### 패킷 손실 높음
1. **케이블 연결**: USB 케이블 상태 확인
2. **보드레이트**: 양쪽 설정이 일치하는지 확인
3. **버퍼 오버플로**: 전송 간격 조정

### GUI 응답 없음
1. **Python 버전**: Python 3.8+ 사용 확인
2. **의존성**: `pip install -r requirements.txt` 재실행
3. **시스템 리소스**: CPU/메모리 사용량 확인
