# 🚀 SAME70 멀티포트 모니터링 가이드

## 🎯 개요
6개의 SAME70-XPLD 보드를 동시에 연결하여 성능을 비교 분석할 수 있는 GUI 도구입니다.

## 🔧 빠른 시작

### 1단계: 도구 실행
```bash
# 자동 설치 및 실행
launch_multiport_monitor.bat

# 또는 수동 실행
pip install -r requirements.txt
python same70_multiport_monitor.py
```

### 2단계: 포트 연결
1. 각 탭에서 COM 포트 선택 (예: COM3, COM4, COM5, ...)
2. 보드레이트 설정 (기본값: 115200)
3. **Connect** 버튼 클릭

### 3단계: 테스트 시작
- **Auto Test**: 자동으로 핑 메시지 전송 (1초 간격)
- **Manual Test**: 수동으로 메시지 전송

## 📊 주요 기능

### 포트별 개별 모니터링
- **연결 상태**: 실시간 연결/해제 상태 표시
- **지연시간**: End-to-End 응답 시간 측정 (ms)
- **패킷 손실률**: 전송 실패율 백분율
- **통계**: 총 전송/수신/손실 패킷 수

### 통합 비교 분석
- **Status 탭**: 모든 포트 상태 한눈에 보기
- **Charts 탭**: 
  - 지연시간 비교 차트 (실시간)
  - 패킷 손실률 비교 차트
  - 처리량(Throughput) 비교
- **Logs 탭**: 
  - 모든 포트 통합 로그
  - 포트별 필터링 기능
  - 로그 저장 (CSV 형식)

## 🎮 사용 시나리오

### 성능 비교 테스트
```
목적: 6개 보드의 UART 성능 동시 측정
방법:
1. 모든 포트 연결
2. Auto Test 활성화
3. Charts 탭에서 실시간 비교 관찰
4. 통계 데이터 분석
```

### 스트레스 테스트
```
목적: 높은 부하 상황에서의 안정성 검증
방법:
1. Test Interval을 최소값(0.1초)로 설정
2. 장시간 자동 테스트 실행
3. 패킷 손실률 모니터링
4. 이상 현상 포트 식별
```

### 프로토콜 디버깅
```
목적: 통신 프로토콜 오류 분석
방법:
1. Manual Test로 특정 메시지 전송
2. Logs 탭에서 상세 통신 내역 확인
3. 포트별 필터로 문제 포트 집중 분석
4. Raw 데이터 검토
```

## 📈 데이터 분석

### 실시간 차트 해석
- **지연시간 차트**: 
  - 정상: 1-10ms 범위
  - 주의: 10-50ms 
  - 경고: 50ms 이상

- **패킷 손실률 차트**:
  - 정상: 0%
  - 주의: 0.1-1%
  - 경고: 1% 이상

### 성능 지표
```
우수한 포트: 지연시간 < 5ms, 손실률 = 0%
보통 포트: 지연시간 5-15ms, 손실률 < 0.5%
문제 포트: 지연시간 > 15ms 또는 손실률 > 0.5%
```

## 🔧 고급 설정

### 테스트 파라미터 조정
- **Test Interval**: 핑 전송 간격 (0.1-10초)
- **Timeout**: 응답 대기 시간 (1-10초)
- **Chart Update**: 차트 갱신 주기 (0.1-2초)

### 로그 관리
- **실시간 로그**: 스크롤 따라가기 옵션
- **필터링**: 포트별, 시간별 필터
- **저장**: CSV 형식으로 분석 데이터 내보내기

## 🚨 문제 해결

### 연결 실패
```
증상: "Failed to open port" 오류
해결:
1. COM 포트 번호 확인 (디바이스 관리자)
2. 다른 프로그램이 포트 사용 중인지 확인
3. USB 케이블 재연결
4. 포트 권한 확인
```

### 높은 지연시간
```
증상: 지연시간이 50ms 이상
해결:
1. USB 허브 사용 시 직접 연결로 변경
2. 시스템 부하 확인 (CPU/메모리)
3. 다른 USB 포트로 변경
4. 보드레이트 확인
```

### 패킷 손실
```
증상: 패킷 손실률이 지속적으로 증가
해결:
1. 케이블 연결 상태 점검
2. 전원 공급 안정성 확인
3. 펌웨어 동작 상태 점검
4. 테스트 간격 늘리기
```

## 💡 활용 팁

### 효율적인 테스트
1. **단계적 연결**: 1개씩 연결하여 각각 안정성 확인 후 추가
2. **기준 포트**: 가장 안정적인 포트를 기준으로 다른 포트들과 비교
3. **환경 변수**: 온도, 습도 등 환경 조건도 기록하여 상관관계 분석

### 데이터 활용
1. **트렌드 분석**: 시간대별 성능 변화 패턴 파악
2. **성능 프로파일**: 각 보드의 고유한 성능 특성 문서화
3. **품질 관리**: 제조 품질 검증 및 불량 보드 식별

---
**참고**: 최대 6개 포트까지 안정적으로 동시 모니터링 가능하며, 더 많은 포트가 필요한 경우 여러 인스턴스를 실행할 수 있습니다.
